# Indian Traffic Analytics System — YOLOv8

This capstone project build a Deep Learning AI model for real-time vehicle DETECTION, tracking, and analytics for urban intersections using YOLOv8. This model is useful to predict accurate detection, robust multi-object tracking, and traffic insights.

**Primary objectives
**
**Detect vehicles** (cars, bikes, buses, trucks, auto-rickshaw) with high precision and recall
**Track vehicles** consistently across frames (ID persistence)
**Count vehicles** per direction and lane in real time
**Estimate traffic** density and occupancy

**Detection vs Classification
**
**Classification: ** Assigns a single label to an entire image (e.g., "car" or "no car"). Suited for image-level tasks.
**Detection:** Localizes and classifies multiple objects with bounding boxes and confidences. Essential for traffic scenes with overlapping vehicles and pedestrians.

**Technology Stack
Python 3.10, Tensor Flow, OpenCV, YOLOv8
